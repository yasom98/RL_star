# RL_star

Codex bağlantı testi başarılı ✅

Bu proje, basit bir grid tabanlı pekiştirmeli öğrenme (Reinforcement Learning) örneği sunar.

## Kurulum

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Çalıştırma

Eğitim döngüsünü çalıştırmak ve Q-tablosunu kaydetmek için:

```bash
python -m rl_star.rl_grid
```

## Testler

`pytest` kullanarak birim testlerini çalıştırabilirsiniz:

```bash
pytest
```
